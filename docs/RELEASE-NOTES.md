Squad Status HUD now includes Squad Alerts. New members fade into the roster, and confirmed deaths get a brief red emphasis. Health bars turn red at 30% or less and pulse slowly at 15% or less, without an extra low-health text notice.

### Installation

1. Download **Squad-Status-HUD-1.1.0-Full.zip** and extract it.
2. Close the game, then open **Squad-Status-HUD-1.1.0-Setup.exe**.
3. Select the main game folder containing **StarshipTroopers_UBW.exe**. In Steam: right-click the game → **Manage → Browse local files**.
4. Click **Install / Update**, then start the game as usual.

If you already use the mod, follow the same steps to update. UE4SS is included.
English is selected by default; use **EN / ไทย** if you prefer Thai.
