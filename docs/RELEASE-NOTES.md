Keep an eye on your squad without aiming at each trooper. Squad Status HUD shows their names and live blue health bars above the minimap. The roster updates as members join, leave or take damage, and stays hidden in menus.

### Installation

1. Download **Squad-Status-HUD-1.0.0-Full.zip** below and extract it.
2. Close the game and open **Squad-Status-HUD-Setup.exe**.
3. Choose the game folder containing **StarshipTroopers_UBW.exe**. You can find it in Steam: right-click the game → **Manage → Browse local files**.
4. Click **Install / Update**, then start the game as usual.
5. Load a mission and recruit some troopers. Their names and health bars will appear above the minimap.

UE4SS is included in the installer. English is selected by default; use **EN / ไทย** if you prefer Thai. To remove the mod, close the game and click **Uninstall** in the installer.

Requires Windows 10/11, .NET Framework 4.8 and Steam build **22832378**. Tested at 1920×1080. See the README if you want to move or resize the roster.

The **Source.zip** download contains the source and build inputs.
